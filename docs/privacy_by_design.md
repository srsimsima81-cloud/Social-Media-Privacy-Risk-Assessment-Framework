# Privacy by Design

## Data Minimization
The application asks whether sensitive information is exposed instead of collecting the actual information.

## Purpose Limitation
Assessment records are used for risk scoring, findings, recommendations and aggregate demonstration.

## Privacy by Default
No real identity, contact value, address, exact location, password or message is required.

## Transparency
The UI and README clearly explain what the system collects and does not collect.

## User Control
The user controls assessment inputs. A production deployment should add authenticated deletion controls.

## Least Privilege
Third-party application recommendations emphasize removing permissions that are not needed.

## Retention Limitation
A production version should configure retention and deletion schedules. The local demo stores only derived records.
