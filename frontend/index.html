Social Media Privacy Risk Assessment Framework

Assess privacy exposure using self-reported, non-sensitive configuration indicators. No real profiles are scraped or tracked.

Start Privacy Assessment Demo Dashboard

What this project assesses

  • Profile and personal-information exposure
  • Location and content exposure
  • Tagging and connection controls
  • MFA and account-security practices
  • Third-party application access
  • Social-engineering awareness
  • Historical digital footprint

Privacy-first by design

The questionnaire asks whether information is visible—not for the actual phone number, email, address, birthday, messages, password, or exact location.

Educational framework only: a score is an exposure estimate, not a guarantee of compromise or safety.
